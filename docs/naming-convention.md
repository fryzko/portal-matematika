# Aturan Penamaan

## File

Gunakan huruf kecil.

Gunakan tanda hubung (-).

Jangan gunakan spasi.

Contoh:

* index.html
* kelas7.html
* kelas8.html
* bilangan.html

## Folder

Gunakan huruf kecil.

Contoh:

* pages
* assets
* images

## CSS Class

Gunakan format:

* main-header
* navigation-menu
* content-card
* footer-section
