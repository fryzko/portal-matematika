# Aturan Pengembangan Portal Matematika

## Tujuan Proyek

Membangun Portal Matematika SMP Indonesia yang mudah dikembangkan secara bertahap.

## Aturan Umum

1. Gunakan HTML5 standar.
2. Gunakan CSS eksternal.
3. Gunakan JavaScript murni (vanilla JavaScript).
4. Jangan menggunakan framework frontend tanpa persetujuan.
5. Kode harus rapi dan mudah dibaca.
6. Beri komentar pada bagian penting.
7. Jangan mengubah struktur folder tanpa persetujuan.
8. Jangan menghapus file yang sudah ada tanpa persetujuan.
9. Semua halaman harus siap diintegrasikan ke Flask di masa depan.
10. Semua data harus dirancang agar dapat dipindahkan ke SQLite di masa depan.

## Penamaan File

* Gunakan huruf kecil.
* Gunakan tanda hubung (-).
* Jangan gunakan spasi.

Contoh:

* kelas7.html
* kelas8.html
* materi-bilangan.html

## CSS

* Gunakan satu file CSS global.
* Hindari CSS yang duplikat.
* Gunakan class yang jelas dan konsisten.

## JavaScript

* Pisahkan JavaScript ke file eksternal.
* Hindari kode yang berulang.

## Dokumentasi

Setiap fitur baru harus dijelaskan secara singkat sebelum dibuat.
