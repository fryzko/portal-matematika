\# Prompt Master 001



Sebelum membuat atau mengubah kode, baca seluruh dokumen dalam folder docs.



Dokumen acuan:



\* roadmap.md

\* fitur.md

\* struktur-database.md

\* codex-rules.md

\* sitemap.md

\* v1-pages.md

\* naming-convention.md

\* design-system.md



Aturan:



1\. Jangan mengubah struktur folder proyek.

2\. Gunakan HTML5 standar.

3\. Gunakan CSS eksternal.

4\. Gunakan JavaScript murni (vanilla JavaScript).

5\. Semua kode harus mudah dibaca dan diberi komentar seperlunya.

6\. Semua halaman harus siap diintegrasikan dengan Flask di masa depan.

7\. Semua data harus dirancang agar mudah dipindahkan ke SQLite.

8\. Jika ragu, ikuti dokumen di folder docs.
