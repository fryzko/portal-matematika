\# Project Brief



Nama Proyek:

Portal Matematika



Tujuan:

Membangun portal pembelajaran matematika SMP yang sederhana, cepat, mudah dipelihara, dan dapat dikembangkan secara bertahap.



Target Pengguna:



\* Siswa SMP

\* Guru Matematika



Teknologi:



\* HTML

\* CSS

\* JavaScript

\* Python (tahap berikutnya)

\* SQLite (tahap berikutnya)



Struktur Utama:



\* Beranda

\* Kelas VII

\* Kelas VIII

\* Kelas IX

\* Kamus Matematika

\* Worksheet

\* Generator Soal

\* Bank Soal

\* Tentang Portal



Versi Saat Ini:

Versi 1.0



Fokus Pengembangan Saat Ini:



\* Menyiapkan struktur frontend

\* Membuat halaman HTML dasar

\* Membuat CSS global

\* Menyiapkan fondasi untuk pengembangan berikutnya



Prinsip Desain:



\* Sederhana

\* Cepat

\* Mudah dibaca

\* Responsif

\* Mirip filosofi Math Is Fun
